## Setup & Instructions

1. Clone the repository.
2. Install Python 3.x and required dependencies (e.g. `jupyter`, `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`).
3. Launch Jupyter Notebook / JupyterLab to view and run the notebooks in each folder.
